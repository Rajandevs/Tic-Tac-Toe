## TIC-TAC-TOE Game

This is a simple implementation of the tic tac toe game using HTML,CSS and JavaScript. In this game you can play agianst the computer. 

---

## Features
-Functional tic tac toe game
- Choosing your own symbol(X or O)
- Play against the computer
- Restart game option

---
## Technologies Used
- HTML5
- CSS3
- JavaScript
